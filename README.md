# CurriVerse X

Try university-level learning for free before committing to a degree. CurriVerse X offers self-study roadmaps, lessons, worked examples, and browser-based activities in English and Persian.

## Try a lesson

- [Physics: position–time graphs and the motion lab](https://curriverse-x.com/lesson/foundation/physics?section=lab)
- [شیمی: مول و جرم مولی، همراه با ترازوی مجازی](https://curriverse-x.com/fa/lesson/foundation/chem?section=lab)
- [Explore all learning paths](https://curriverse-x.com/explore)

## Give feedback or contribute

- Open a GitHub issue for a site bug, an accessibility problem, or a suggestion about how the site works. Include the page link and what you expected to happen.
- Use the [Contribute page](https://curriverse-x.com/contribute) to propose lesson edits, translations, or standalone study material.
- For a small first contribution, try reviewing a Persian lesson for clarity, checking a diagram with a screen reader, or suggesting a free primary reading.

This repository is the public project and feedback hub for CurriVerse X.
